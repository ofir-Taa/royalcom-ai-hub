סטטוס

הריפו ofir-Taa/Task-system קיים ב-GitHub באמת — הקישורים למטה פותחים אותו בפועל. הפורטל הזה אינו מחובר ל-GitHub API: אין קריאה אוטומטית של Issues/PR, ואין יצירת Issue מהשרת — כל פעולה בפועל קורית בדפדפן שלך, מחוברת לחשבון ה-GitHub שלך.
📁 הריפו Issues Pull Requests Actions 💬 צ'אט עם יובל

תהליך עבודה מומלץ

  1. פתח Issue מפורט (ראה טופס מתחת) — כל משימה מתחילה מ-Issue, לא מקוד ישר.
  2. צור ענף מה-Issue: feature/<מספר>-תיאור-קצר או fix/<מספר>-תיאור-קצר.
  3. פתח PR מוקדם (Draft) כדי לקבל נראות על העבודה בתהליך.
  4. לפני בקשת Review: הרץ בדיקות/לינט מקומית, עדכן תיעוד אם רלוונטי.
  5. מזג רק אחרי Review ואחרי שה-CI (אם קיים) עבר בירוק.
  6. פריסה לייצור/שינוי מערכות חיות — רק באישור מפורש, לפי agents-registry.json.

הכנת Issue

פתח Issue חדש ב-GitHub

הכפתור "פתח Issue חדש ב-GitHub" ממלא מראש כותרת ותוכן בטופס ה-Issue האמיתי של GitHub — עדיין יש ללחוץ "Submit" שם כדי לפתוח אותו בפועל.

אין גישת API ל-GitHub מהפורטל הזה. כל קישור פותח את GitHub האמיתי בדפדפן שלך.
