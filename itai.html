לא נבדק עדיין

Royal Network Insight היא אפליקציה נפרדת שרצה מקומית בכתובת http://127.0.0.1:8080 — רק במחשב שעליו היא מופעלת. הפורטל הזה אינו מחובר אליה באמצעות API: הבדיקה למטה היא "פינג" זמינות בלבד (בודקת אם משהו מקשיב על הפורט), לא קריאת מידע אמיתית מהמערכת.

מדריך אבחון — שימוש כרשימת בדיקה

תוכן עיוני כללי לעבודה בשטח. אינו נשלף ממערכת חיה ואינו מחליף תיעוד רשת פנימי של רויאלקום.

תקלת VLAN / קישוריות
  1. אמת לאיזה VLAN מוגדר הפורט של המכשיל (access / trunk, ה-VLAN ID והאם tagged/untagged).
  2. בדוק שה-VLAN מוגדר וקיים גם במתג המקור וגם במתג המרוחק (ולא רק ב-interface אחד).
  3. ודא שהקישור בין המתגים (uplink/trunk) מעביר את ה-VLAN הרלוונטי (allowed VLAN list).
  4. בדוק טבלת ARP / MAC לראות אם המכשיר בכלל "נראה" ברשת מהצד השני.
  5. אם יש מספר VLAN-ים חדשים — בדוק הגדרות routing/inter-VLAN (ACL, Firewall) שלא חוסמות.
מתגים ופורטים
  1. בדוק מצב פיזי של הפורט: Link/Activity LED, מהירות ו-duplex שהתאמה (לא auto מול fixed).
  2. בדוק סטטוס הפורט בניהול המתג: up/down, errors, CRC, collisions, broadcast storm.
  3. בדוק אם הפורט מוגדר ב-Err-disable / security violation (port security, storm-control).
  4. החלף כבל/פורט לבדיקה כדי לשלול תקלת חוט.
  5. אם רלוונטי — בדוק PoE: הספק זמין, budget לא נגמר, המכשיר מזוהה ומקבל מתח.
מצלמות ו-NVR
  1. ודא שהמצלמה מקבלת כתובת IP תקינה (סטטית/DHCP) ושאין התנגשות כתובות.
  2. בדוק רוחב פס ו-bitrate בפועל מול יכולת הרשת/PoE, בעיקר אם יש הקפאות/טשטוש.
  3. בדוק סנכרון זמן (NTP) בין המצלמה, ה-NVR והרשת — שגיאות זמן גורמות לבעיות הקלטה.
  4. אשר שה-NVR מצליח "לראות" את המצלמה ברשת (ping/ONVIF) לפני בדיקת תצורה.
  5. בדוק מקום אחסון פנוי ומצב דיסקים ב-NVR אם ההקלטה מפסיקה.
SNMP וניטור
  1. אמת community string / SNMPv3 credentials תואמים בין המתג למערכת הניטור.
  2. בדוק שה-ACL של המתג מתיר את כתובת ה-IP של שרת הניטור לפנות ב-SNMP.
  3. בדוק אם ה-OID המבוקש נתמך בגרסת ה-firmware של המכשיר.
  4. בדוק טראפ (traps) מול polling — לעיתים רק אחד מהם מוגדר/פתוח בפיירוול.

הכנת פתק תקלה

מלא פרטים כדי להכין תיאור תקלה מסודר — להעתקה או להמשך שיחה עם איתי.

סביבת עבודה מקומית. אין קריאת API חיה למערכת הרשת — רק קישור יציאה ובדיקת זמינות.
